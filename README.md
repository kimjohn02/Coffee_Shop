# ☕ Coffee Shop - Flutter & Dart App

A modern Coffee Shop mobile and multi-platform application built with **Flutter 3.47** and **Dart 3.13**.

---

## 🚀 Features

- **Material 3 Design**: Warm artisan coffee color palette and sleek card layouts.
- **Dynamic Catalog**: Categorized coffee & pastry list (Espresso, Latte, Cappuccino, Cold Brew, Pastries).
- **Search & Filter**: Real-time keyword search and category chip filtering.
- **Interactive Cart**:
  - Live badge counter in the top bar and bottom navigation.
  - Interactive bottom sheet to add/remove items and adjust quantities.
  - Automatic subtotal, delivery fee, and grand total calculation.
- **Multi-Platform Support**: Ready for Android, Windows Desktop, and Web (Chrome/Edge).

---

## 📱 Running the App

### 1. Run on Android Emulator

To launch your configured Android emulator:
```bash
flutter emulators --launch Medium_Phone_API_37.0
```

Once the emulator boots up, run:
```bash
flutter run
```
Or target the Android device directly:
```bash
flutter run -d android
```

---

### 2. Run on Chrome (Web)

```bash
flutter run -d chrome
```

---

### 3. Run on Windows Desktop

```bash
flutter run -d windows
```
